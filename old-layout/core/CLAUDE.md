# core - Shared UI Library

CRITICAL: MUST read and follow [`AGENTS.md`](AGENTS.md) in this directory for
module-specific architecture, key files, and conventions.

Kobweb library with cross-feature UI primitives (theme, foundation, layout,
text, components) plus JS-only bindings (Firebase, analytics). Consumed by
`:site` and `:resources`.

```bash
./gradlew :core:build
```
