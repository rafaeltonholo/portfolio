# Impeccable Design Context

## Design Context

### Users

Personal portfolio for Rafael Tonholo. Mixed audience:

- **Senior engineers and peers** evaluating craft, code samples, writing, and
  technical depth - credibility signal, referrals, open-source collaboration.
- **Hiring managers and recruiters** scanning for role fit, recent work,
  impact, and contact paths - goal is intro call or offer.

Typical session: desktop browser, either evening (peers) or work hours
(recruiters). Not a phone-first product, but must work cleanly on mobile since
links get shared in Slack/DMs.

### Brand Personality

Three words: **precise, opinionated, handmade**.

- Speaks in the language of engineers without cosplaying "developer" tropes.
- Confident enough to have a point of view on typography, spacing, and code.
- Feels built by a craftsman, not assembled from a template.

Emotional goals: trust, curiosity, respect for craft. Not delight, not
playfulness, not "fun."

### Aesthetic Direction

**IDE / technical craft**: mono-driven display voice (JetBrains Mono),
editorial serif accent (Fraunces) for long-form prose, neutral sans (Geist)
for body UI. Mint accent used sparingly as the single 10% color.

- Treat the portfolio like a well-configured editor: considered tokens, clear
  semantic hierarchy, density control, code as first-class texture.
- Both light and dark modes are first-class - neither is the canonical look.
  Pick the theme from viewing context (OS pref), not from author preference.
- Asymmetric layouts, generous space around hero moments, tight clusters in
  meta rows.

### Anti-references (what this MUST NOT look like)

- Generic dev portfolio template (hero + 3 cards + skill chips + contact
  form).
- AI-cyan-on-dark SaaS look (neon, glassmorphism, purple-to-blue gradients,
  mesh backgrounds).
- Corporate agency site (stock photography, bland grids, voice-less copy).
- Over-animated showcase (parallax everywhere, scroll-driven reveals on every
  section, demo-reel motion).

### Design Principles

1. **Earn every element.** No decorative filler. If a chip, icon, or card is
   not doing work, remove it.
2. **Type does the heavy lifting.** Size and weight contrast create hierarchy
   before color ever enters the picture.
3. **One accent, used rarely.** Mint is a punctuation mark, not wallpaper.
   Neutrals carry the site.
4. **Content dictates layout.** Projects, articles, and resume each get a
   shape that fits the content, not a single repeated template.
5. **Motion only where it means something.** Feedback on state change, focus,
   and navigation. No scroll reveals, no parallax, no flair-for-flair.
